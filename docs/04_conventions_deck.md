# Conventions de présentation

## Page « Allocation & Positioning »

*Reprise du TCP Kenz Global Alpha Fund (Tiger Capital Partners, mai 2025).*

**Le principe :** organiser la page par **région**, pas par classe d'actifs,
et faire figurer pour chaque poste une flèche de positionnement à trois temps.

```
                        Start    Prior     Now
Actions US                 0       +1       −1
Actions Europe            +1       +1       +2
Actions Japon              0        0       +1
Souverain EUR             −1        0       +1
```

**Pourquoi c'est bon.** Une allocation affichée en poids décrit un *état*.
Le triptyque Start / Prior / Now décrit une **décision** : d'où l'on vient,
ce qu'on a fait, et pourquoi maintenant. Le client suit un raisonnement au
lieu de lire un camembert.

Chaque ligne est accompagnée de deux ou trois puces de justification —
courtes, factuelles, avec le driver explicite (valorisation, momentum des
BPA, duration, couverture contre un risque nommé).

**Adaptation au dossier Lauren.** La colonne « Start » est le point d'entrée
du mandat, puisqu'il n'y a pas d'historique de gestion. Les trois temps
deviennent donc : **Neutre (benchmark) / Cible SAA / Positionnement tactique**.
Cela montre au client que l'allocation stratégique et les paris tactiques sont
deux décisions distinctes — ce qui est aussi ce que mesure le benchmark
hybride (§13 de l'argumentaire).
